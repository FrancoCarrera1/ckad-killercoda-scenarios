# The Application Autopsy

The entire three-tier application stack is down. The database pod is Pending, the backend pod is in Error state, and the frontend is in CrashLoopBackOff. Each tier has a different root cause. Your job is to perform a systematic autopsy, fix each layer, and bring the full stack back to life.

In this scenario, you will:
- Debug a Pending pod with storage issues
- Fix an Error state pod with configuration problems
- Resolve a CrashLoopBackOff caused by missing dependencies
- Verify the complete application stack recovery

This is a realistic multi-layer debugging challenge. Time to perform the autopsy!

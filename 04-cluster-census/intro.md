# The Cluster Census

Welcome to kubectl output mastery!

## Scenario

The audit team needs a comprehensive inventory of your Kubernetes cluster. You'll practice listing, filtering, sorting, and formatting kubectl output — essential skills for the CKAD exam where speed and precision matter.

Being able to quickly extract information from kubectl is a **critical exam skill**. You need to:
- Filter resources by namespace
- Sort by different fields
- Extract specific data with JSONPath
- Format output with custom columns
- Save output to files for documentation

## Learning Objectives

By the end of this scenario, you will be able to:
- List resources and save to files
- Use `--all-namespaces` to see cluster-wide resources
- Sort resources by creation time and other fields
- Extract specific fields using JSONPath
- Create custom output columns
- Understand when to use different output formats

## CKAD Exam Relevance

This scenario covers **Core Concepts** (13% of the exam) and general kubectl proficiency that applies to ALL domains. Output formatting questions appear throughout the exam, and being fast at kubectl is essential to finish on time!

## Output Formats You'll Master

1. **Default**: Human-readable tables
2. **-o wide**: Additional columns
3. **-o yaml/json**: Full resource definitions
4. **-o jsonpath**: Extract specific fields
5. **-o custom-columns**: Custom table formatting
